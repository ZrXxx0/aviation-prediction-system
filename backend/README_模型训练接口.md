# 模型训练接口使用说明

## 功能概述

本接口允许用户通过HTTP POST请求来训练航空需求预测模型。无论训练成功还是失败，系统都会在数据库中创建相应的记录，便于追踪和管理。

## 快速开始

### 1. 启动Django服务器

```bash
cd backend
python manage.py runserver
```

### 2. 发送训练请求

```bash
curl -X POST http://localhost:8000/predict/train/model/ \
  -H "Content-Type: application/json" \
  -d '{
    "origin": "CAN",
    "destination": "PEK",
    "config": {
      "time_granularity": "monthly",
      "model_type": "lgb",
      "test_size": 0.2
    }
  }'
```

### 3. 查看训练结果

接口会返回训练状态和创建的数据库记录ID。您可以使用这个ID在Django管理界面中查看详细的训练记录。

## 接口特性

- ✅ **自动记录**: 无论成功失败都会创建数据库记录
- ✅ **参数验证**: 自动验证请求参数的完整性和有效性
- ✅ **错误处理**: 完善的异常处理和错误信息返回
- ✅ **异步友好**: 支持长时间运行的训练任务
- ✅ **详细日志**: 完整的训练过程日志记录

## 支持的配置

### 时间粒度
- `yearly`: 年度数据
- `quarterly`: 季度数据  
- `monthly`: 月度数据（推荐）

### 模型类型
- `lgb`: LightGBM（推荐，训练速度快）
- `xgb`: XGBoost（精度高，但训练较慢）

### 其他参数
- `test_size`: 测试集比例（0.1-0.5）
- `add_ts_forecast`: 是否添加时间序列特征
- `arima_order`: ARIMA参数 [p,d,q]

## 测试

运行测试脚本验证接口功能：

```bash
cd backend
python test_train_api.py
```

## 注意事项

1. **训练时间**: 首次训练可能需要5-15分钟
2. **数据要求**: 确保航线有足够的历史数据
3. **资源消耗**: 训练过程会占用较多CPU和内存
4. **并发限制**: 建议同时只运行1-2个训练任务

## 故障排除

### 常见问题

1. **连接错误**: 确保Django服务器正在运行
2. **参数错误**: 检查请求体格式和必需参数
3. **训练失败**: 查看返回的错误信息和数据库记录
4. **超时错误**: 增加客户端超时时间设置

### 获取帮助

如果遇到问题，请检查：
- Django服务器日志
- 数据库中的训练记录
- 返回的错误响应信息
