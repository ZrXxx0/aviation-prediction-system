# 数据库初始化说明

## 步骤1：创建数据库迁移文件

```bash
cd backend
python manage.py makemigrations accounts
```

## 步骤2：执行数据库迁移

```bash
python manage.py migrate
```

这将创建以下表：
- `user` - 用户表
- `role` - 角色表
- Django默认的其他表（如auth_permission等）

## 步骤3：初始化角色数据

```bash
python manage.py init_roles
```

这将创建三个默认角色：
1. **超级管理员** (super_admin) - 拥有所有权限
2. **管理员** (admin) - 可以查看数据看板、预测模块和数据管理
3. **游客** (visitor) - 只能查看数据看板

## 步骤4：创建第一个超级管理员用户

### 方法1：使用Django Shell

```bash
python manage.py shell
```

然后在shell中执行：

```python
from accounts.models import User, Role

# 获取超级管理员角色
super_admin_role = Role.objects.get(name='super_admin')

# 创建超级管理员用户
user = User.objects.create_user(
    username='admin',
    email='admin@example.com',
    password='your_password_here',  # 请修改为你的密码
    role=super_admin_role
)
print(f"创建用户成功: {user.username} (邮箱: {user.email})")
```

### 方法2：使用Django Admin后台

1. 先创建一个超级用户（用于登录Django Admin）：
   ```bash
   python manage.py createsuperuser
   ```

2. 启动Django开发服务器：
   ```bash
   python manage.py runserver
   ```

3. 访问 http://localhost:8000/admin/ 登录

4. 在后台中：
   - 进入"角色"部分，确认三个角色已创建
   - 进入"用户"部分，创建新用户并分配"超级管理员"角色

## 步骤5：测试登录

使用创建的超级管理员账号登录前端系统，验证功能是否正常。

## 注意事项

1. **密码安全**：生产环境中请使用强密码
2. **邮箱唯一性**：每个用户的邮箱必须是唯一的
3. **角色分配**：新创建的用户默认没有角色，需要手动分配
4. **权限检查**：前端会根据用户角色自动显示/隐藏相应的菜单和功能

## 角色权限说明

### 超级管理员 (super_admin)
- ✅ 查看数据看板
- ✅ 查看预测模块
- ✅ 查看数据管理
- ✅ 查看系统管理（用户管理）

### 管理员 (admin)
- ✅ 查看数据看板
- ✅ 查看预测模块
- ✅ 查看数据管理
- ❌ 查看系统管理

### 游客 (visitor)
- ✅ 查看数据看板
- ❌ 查看预测模块
- ❌ 查看数据管理
- ❌ 查看系统管理
